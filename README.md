## 项目简介

本仓库是 **医学生龙虾技能（Medicine-StudentClaw Skills）** 的汇总索引，整合了基于人民卫生出版社最新版教材整理的一系列 AI 医学技能集。每个子项目均以课本为核心，将知识点重构为可交互的临床技能，帮助医学生和临床医师高效学习与检索。

**核心特点：**
- 📚 基于人卫社最新权威教材（第 8/9/10 版）
- 🧠 AI 驱动的技能交互与即时问答
- 🔍 覆盖基础与临床核心学科
- 📊 标准化技能分类与索引体系

## 快速开始

### 使用方式

每个技能集均包含标准化的技能结构：

1. **技能注册表**（`SKILL.md`）— 核心配置与技能元数据
2. **技能详情**（每个技能独立目录中的 `SKILL.md`）
   - 使用时机 — 何时触发该技能
   - 执行步骤 — 标准化操作流程
   - 注意事项 — 禁忌与警示
   - 参考文档 — 详细补充资料
3. **搜索工具**（`scripts/`）— 按关键词检索技能
4. **配置与测试**（`config/` + `tests/`）— 技能分类配置与完整性校验

### 提问策略

选择对应技能集后，可以通过以下方式交互：

- **概念查询** — 直接提问学科核心概念与定义
- **临床案例分析** — 输入病例信息进行鉴别诊断分析
- **考试题目** — 模拟选择题与解析

具体示例请见各学科 README 文档。

### 安装

> 各学科的安装指令请见对应的独立 README 文件。
